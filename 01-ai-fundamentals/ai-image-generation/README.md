# Project 02: AI Image Generation with Google Gemini

**Course:** Google AI Professional Certificate  
**Module:** AI Fundamentals  
**Lab:** Create Custom Images with Gemini

## Project Overview

This project demonstrates how generative AI can be used
to create and refine educational materials for workplace
cybersecurity awareness.

Using Google Gemini, I developed a cybersecurity poster
titled "Anatomy of a Phish" to help employees identify
common phishing email warning signs.

## Project Objectives

- Explore AI-assisted visual brainstorming.
- Develop effective image-generation prompts.
- Generate a professional cybersecurity awareness poster.
- Evaluate AI-generated images for accuracy and readability.
- Refine images through iterative prompting.

## Project Workflow

### 1. Creative Brainstorming
Used Gemini to generate three visual concepts for a
cybersecurity awareness poster.

Selected "Anatomy of a Phish" for its educational value.

### 2. Content Development
Generated three text variations and selected a concise,
action-oriented version.

### 3. Image Generation
Created an infographic featuring a fictional phishing
email and four common warning signs.

### 4. Image Refinement
Identified spelling errors, nonsensical text, and
overlapping annotations in the initial image.

Used two additional prompts to improve the design,
simplify the email content, and correct errors.

## Key Takeaway

AI image-generation tools can produce useful educational
visuals, but generated text and technical information
must be reviewed carefully.

Simplifying complex visual instructions improved the
accuracy and readability of the final poster.
