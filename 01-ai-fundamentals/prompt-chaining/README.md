# Project 01: Prompt Chaining with Google Gemini

**Course:** Google AI Professional Certificate
**Module:** AI Fundamentals
**Lab:** Practice Prompt Chaining in Gemini

## Project Overview

This project demonstrates how prompt chaining can be used to break down a complex business decision into smaller, connected tasks.

Using Google Gemini, I explored opportunities to expand an operations consulting business into AI-enabled services.

The exercise involved three stages:
1. Brainstorming potential business services.
2. Evaluating the feasibility of each option.
3. Developing a seven-day implementation plan.

- Google Gemini
