# Project 05: AI-Powered Knowledge Hub

**Training:** Google AI Professional Certificate  
**Course:** AI for Brainstorming and Planning  
**Lab:** Build with AI — Knowledge Hub  
**AI Tool:** Google NotebookLM  
**Status:** Completed

## Project Overview

I created an AI-powered knowledge hub using Google NotebookLM to organize, retrieve, and analyze information from multiple project documents.

The knowledge hub focused on a proposed AI-Assisted Phishing Analyzer, a cybersecurity awareness application designed to help small businesses identify suspicious emails.

The objective was to explore how AI can improve information retrieval, document comparison, and project coordination.

## Project Documents

I uploaded three documents:

1. AI-Assisted Phishing Analyzer — Project Launch Memo
2. AI-Assisted Phishing Analyzer — Original Workback Schedule
3. AI-Assisted Phishing Analyzer — Updated Four-Week Workback Schedule

These documents contained project objectives, technical requirements, development milestones, and security considerations.

## Project Workflow

### Step 1: Create a Knowledge Hub

I created a notebook in Google NotebookLM and uploaded the three project documents.

The documents served as the knowledge base for answering questions about the project's development timeline and security requirements.

### Step 2: Analyze Project Documents

I asked NotebookLM to compare the original and updated development schedules.

The analysis focused on cybersecurity improvements, particularly secure API key management.

NotebookLM identified changes involving:

- Git initialization and credential exclusions
- API billing and usage controls
- Secure environment variable configuration
- Streamlit secrets management
- API authentication and error handling
- Credential verification before publishing code

### Step 3: Review AI-Generated Findings

I evaluated NotebookLM's response against the project documents.

The analysis successfully identified major scheduling changes and dependencies.

However, I recognized that the availability of hard API spending caps required independent verification.

This reinforced the importance of validating AI-generated recommendations rather than accepting them without review.

### Step 4: Explore Collaboration and Access Controls

I explored NotebookLM's sharing functionality and reviewed the available access permissions.

I configured the notebook for restricted access and disabled copying.

This exercise demonstrated how access controls can help manage the distribution of project information.

No team invitations were sent.

## Key Takeaways

AI-powered knowledge hubs can help teams retrieve relevant information from multiple documents without manually searching each file.

Source-based analysis is particularly useful when comparing project plans, reviewing requirements, and identifying changes.

However, AI-generated responses still require human verification, especially when they involve technical or financial assumptions.
