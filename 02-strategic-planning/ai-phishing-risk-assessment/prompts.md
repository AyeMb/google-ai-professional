# AI Prompts — Project 04

**AI Tool:** Google Gemini  
**Lab:** Build with AI — Risk Assessment

## Prompt 1: Identify Missing Dependencies

Act as an experienced IT project manager specializing in AI
application development and cybersecurity.

Review the attached AI Phishing Analyzer Launch Memo and
Workback Schedule.

Identify missing dependencies that could delay development,
increase costs, create security vulnerabilities, or affect
application quality.

For each dependency, explain:
1. What is missing
2. Why it matters
3. Potential project impact
4. Recommended corrective action

Prioritize dependencies by risk level: High, Medium, or Low.

Focus on practical considerations for a beginner developer
working with a limited budget.

## Prompt 2: Assess Security Risks

Let's focus on the missing dependency:
Secure API Key Management.

How could failing to implement secure API key storage affect
the development and launch of our AI-Assisted Phishing Analyzer?

Analyze security risks, financial consequences, development
delays, GitHub credential exposure, and Gemini API integration.

Create a risk assessment table containing:
- Risk
- Likelihood
- Impact
- Mitigation Strategy

Distinguish preventive security controls from actions taken
after a credential has been compromised.

## Prompt 3: Revise the Project Timeline

Create an updated four-week project timeline for the
AI-Assisted Phishing Analyzer.

Focus on secure API key management.

Use the original Project Launch Memo and Workback Schedule
as the baseline.

Include:
- Secure API key storage milestones
- Environment variables and .gitignore configuration
- Streamlit secrets management
- GitHub credential exposure checks
- API authentication and error handling
- Compromised credential response procedures

Format the schedule with:
- Week/Day
- Task
- Dependency
- Risk Level
- Completion Criteria

Identify missing tasks, rescheduled activities, and
milestones blocked by unmet security requirements.

Keep the original four-week development timeline where possible.

Do not assume billing alerts enforce hard spending limits.
