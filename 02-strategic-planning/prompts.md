# AI Prompts — Project 05

**Tool:** Google NotebookLM
**Lab:** Build with AI — Knowledge Hub

## Project Context

I uploaded three documents related to a proposed
AI-Assisted Phishing Analyzer:

1. Project Launch Memo
2. Original Workback Schedule
3. Updated Four-Week Workback Schedule

The objective was to use AI to retrieve and compare
information across multiple project documents.

## Prompt 1: Compare Project Schedules

Compare the original Project Workback Schedule with the
Updated Four-Week Workback Schedule.

What changes were made to address cybersecurity risks,
particularly secure API key management?

Identify the specific tasks, deadlines, and dependencies
that changed.

Cite the source documents supporting your findings.

## Evaluation Approach

I reviewed NotebookLM's response to determine whether it:

- Identified the major scheduling changes.
- Recognized secure credential storage as a prerequisite
  for Gemini API integration.
- Explained the changes in project dependencies.
- Supported its findings with the uploaded documents.

I also evaluated whether the AI repeated technical
assumptions that required independent verification.

## Human Oversight

NotebookLM was used for document analysis, not for
implementing the proposed application.

Its findings were reviewed for accuracy and consistency
with the uploaded project documents.
