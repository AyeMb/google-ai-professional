# Project 05: AI Knowledge Hub — Results

**Tool:** Google NotebookLM  
**Lab:** Build with AI — Knowledge Hub  
**Status:** Completed

## 1. Knowledge Hub Setup

Created an AI-powered knowledge hub using three documents:

- AI-Assisted Phishing Analyzer Launch Memo
- Original Project Workback Schedule
- Updated Four-Week Workback Schedule

The objective was to retrieve and compare information
across multiple project documents.

## 2. Document Comparison Results

NotebookLM identified six significant changes.

| Day | Original Plan | Updated Plan |
|---|---|---|
| 3 | Development environment setup | Initialize Git and configure .gitignore |
| 4 | Obtain Gemini API access | Add billing and usage controls |
| 5 | Design application workflow | Configure secure credential storage |
| 8 | Integrate Gemini API | Integrate API using securely stored credentials |
| 9 | Develop phishing analysis prompt | Add authentication and error-handling tests |
| 19 | Upload project files | Verify credentials are not exposed before publication |

## 3. Dependency Analysis

NotebookLM identified several important dependencies.

**Week 1: Security Setup**

Secure credential storage and repository configuration
must be completed before API integration.

**Week 2: API Integration**

Day 8 API integration depends on the secure credential
storage configured during Week 1.

**Week 4: Final Verification**

Credential exposure checks must be completed before
publishing application files.

## 4. Critical Evaluation

NotebookLM successfully identified major scheduling
changes and security dependencies.

However, its response repeated an assumption from the
updated schedule that hard API spending caps were available.

This assumption requires independent verification.

The exercise demonstrated that source-based AI analysis
can accurately summarize documents while also repeating
unsupported assumptions contained in those documents.

## 5. Collaboration and Access Controls

Explored NotebookLM's sharing functionality.

Actions completed:

- Reviewed notebook access permissions.
- Configured restricted access.
- Disabled copying.

No team invitations were sent.

Successfully created a document-based knowledge hub,
